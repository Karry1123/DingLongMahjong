# 沙盒：实战参考

- 目标：现实牌桌旁单手速查，只录自己的牌，不必模拟四家行动。
- 进入 `/sandbox` 即显示紧凑设置、手牌与全牌种键盘，不经过开局流程。
- 录手牌：点键盘加入，未录满时点手牌移除；满 14 个牌型位自动推荐。
- 设财神／门风／庄家：顶部直接设置并记忆；点“财神”后点键盘选牌。
- 推荐：手牌焦点用亮金标记；一行展示向听与有效进张，候选按需展开。
- 摸打：满手点任意手牌打入自己牌河，再点键盘摸一张，自动更新推荐。
- 修正：可切换“改手牌”直接增删；撤销恢复上一步，包括副露和重置。
- 副露：点入口，选三／四张已有手牌，确认吃／碰／杠；杠后补摸一张。
- 场上已见牌：折叠区开启录入后，共用键盘计入汇总废牌，不区分对手座位。
- 重置：清空手牌、副露和已见牌，保留设置；返回首页始终可达。
- 信息层级：当前手牌与推荐优先，键盘紧随其后，牌河与高级信息置后。
- 手机：七列键盘、手牌换行，每个点击区至少 44px，避免横向舞台缩放。
- 桌面：限制内容宽度，沿用同一交互，不改 PvE／PvP 舞台几何。
- 旧全景沙盘通过“高级：全景推演”进入，可返回速查；两者牌局独立。
- 不输入对手信息时，推荐只依据自己的牌和已知废牌，不代表完整实战局势。
