## 结论与下一轮建议

本轮未满足全部门槛，不晋升；候选与完整证据留在 backend/data/ai_tuning/v3-round1/。均值为正也不能替代置信下界、行为和压力门槛。
本机缩减实验不等同计划原样本量的统计功效；关键分层或稀有杠不足须明确保留为证据不足。下一轮先补足低频专项固定状态与有收益/被支配分类，完成V2历史实现可核验快照；再用新的锁定ID与全新留出墙重试。若本轮净分区间跨零，保持现任并先扩大训练敏感度探针，不按留出结果反向调参或复用验证墙。
