# v0.4.0-beta

### 更新摘要

- 账号体系：账号 + 密码注册，注册必须提供站长本地生成的一次性注册码（`backend/scripts/registration_codes.py` 生成 / 导入 / 撤销 / 列表）；scrypt 密码哈希、不透明 Bearer token、登录限流、改密与登出撤销
- 好友对战：按账号搜索并添加好友，邀请 1～3 位好友直接开桌，空位由 AI 补齐；取消六位房间号与公开匹配，旧 `/api/rooms` 返回 410
- 联机稳定性：断线 60 秒重连宽限取代立即解散；WebSocket 首条消息鉴权；同账号单桌单连接；服务重启中止未结束对局
- 网页前端：vue-router 路由、竖屏应用壳（首页 / 好友 / 牌谱 / 设置底部 Tab）、登录 / 注册 / 好友 / 邀请 / 等待 / 牌谱 / 设置页面，牌桌继续复用横屏舞台
- 手机 App：Capacitor 8 工程（Android / iOS），原生会话持久化、牌桌横屏锁定、常亮、前后台重连、返回键处理；App 与网页共用页面与协议
- AI：权重 V1 固化接入、离线仿真与调参工具链、V2 副露参数实验记录、EV 权重 V3 自动调优设计（解冻优先级、防策略坍塌、基准池评估）
- 验证：后端 505 项 + 17 子测试通过；前端 124/125 通过（1 项既有失败）；网页与 App 构建通过；Android Gradle 与真机未验证
