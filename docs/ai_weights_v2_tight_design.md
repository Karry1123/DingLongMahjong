# V2 硬过滤与窄边界重搜

历史批次 `v2-claims-formal` 的结果和报告保留；其净分退化不能单独证明具体参数的因果贡献。
本批次在冻结 V1 全部165项基础权重的前提下搜索5项副露参数。

| 参数 | 界限 | 初值 |
| --- | --- | ---: |
| 冗余吃牌惩罚 | 45~60 | 55 |
| 吃后向听不降惩罚 | 15~22 | 18 |
| 直接听牌奖励 | 35~45 | 40 |
| 碰底胡激励 | 0.8~1.25 | 1 |
| 杠风险系数 | 0.9~1.1 | 1 |

吃牌分支先模拟冻结V1舍牌策略的最优弃牌。如果弃牌与吃入牌同质，且前后均听牌、逐张听口、剩余数量、底胡、最终胡数及硬胡标记完全相同，直接移出AI可选动作池。审计评分保留负无穷行，不能靠罚分或奖励重返候选池。牌规合法动作仍保留，手动玩家不受此策略过滤影响。过滤一种吃法不妨碍其他有收益的吃法、碰、杠或胡。

吃碰与过牌仍共用待摸状态估值及向听惩罚。上一版已听牌PASS额外补偿22+进张奖励，与Rem/8重复，本次去掉。未听牌的摸牌机会补偿保留；每减少一向听使用相同V1基础向听权重，不另缩放副露推进收益。正常吃后进听、役牌碰和有收益明杠测试继续通过。

原24项专项测试保留，新增硬过滤候选池、胡分改善不能误过滤、晋升门槛检查，共29项。相关配置与离线工具回归共55项通过。

正式运行：1轮、6组候选（含基准参数）各500局快筛；锁定最优一组，在全新牌墙与V1各跑2000局完整EV。V0/V1混合对手池、物理座位轮转及四方轮庄不变。不得复用旧验证牌墙。

晋升门槛按用户最新要求：平均配对净分增益>0且V2放铳率<=V1，专项测试通过，至少500个四局牌墙块。单侧95%下界仍展示，但本批次不以该下界作为门槛；均值为正不等于统计显著。
