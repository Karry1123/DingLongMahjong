# V1 冗余吃牌硬过滤补丁

本次在生产 `app/core/call_decision.py` 单独加入策略过滤。当前
`ai_weights_optimized.json` 全部权重保持不变，不引入未晋升的 V2 估值或参数。

只有同时满足以下条件才禁止 AI 推荐该吃法（玩家的吃、过合法选项均保留）：

1. 吃牌后按现有 V1 策略选择的最优弃牌与被吃牌同质。
2. 吃前、弃牌后均为听牌（向听0）。
3. 在相同公开未知牌池下，逐张和牌牌种、剩余张数、底胡、最终胡数、收益及硬胡标记完全一致，并且听口非空。

过滤在副露奖励与罚分之前执行；不影响其他有收益的吃法、碰、杠、胡。
权威动作生成器仍保留规则合法性，手动副露规则与联机路由均不修改。
该吃法仍返回在 candidates 和 available_actions 中，可手动操作；其硬规则调整评分为 PASS EV 减1，并附原样打回无收益的说明。这是推荐约束评分，并非重新模拟所得的原始EV。AI在这些受限吃法加入展示列表之前选择动作，避免参数或动作顺序覆盖硬规则。HTTP返回有限数值，避免JSON序列化异常。

GM-86F219 在 V1 新代码下推荐 PASS，PASS原评分99保持；吃牌评分98，吃和过两个选项均保留，玩家可自行选择。
正常1→0向听吃牌继续推荐CHI；胡数提高的同宽听口不会被视为相同。

验证覆盖V1专项、历史副露、配置加载、game/step API与V2专项；额外检查动作顺序反转后仍推荐过牌且保留玩家选项。
原V0/V1离线冻结策略仍保存历史实现，未修改旧实验结果。这项生产逻辑补丁未重新完成大样本晋升检验，不能将原4000局统计直接当作补丁后的战绩。
